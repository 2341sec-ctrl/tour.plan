02 / THE DECISIONS

우리 여행의 세 가지 선택

각 카드를 누르면 아래에 선택 조합이 정리됩니다. 선택 내용은 이 브라우저에 저장됩니다.

01

첫날 어디서 잘까?

비교 포인트 · 도착 후 운전 부담 / 숙소와 공원 입구 간 거리 / 체크인 가능 시간
함께 결정 · 공원 코스

초안 예상: 4~6시간. 코스별 소요시간·출발 입구·운영 여부는 예약 전 확인.

02

섬일까, 해안 도시일까?

비교 포인트 · 섬 체류 선호 / 선적·대기 시간 / 두브로브니크 이동 / 투어 출항지
블루라군 투어 확인두 안 모두 투어를 포함하지만, 같은 상품으로 가정하지 않기. 방문 장소와 출항지가 숙박 거점에 맞는지 확인.
03

마지막 3박의 방식

비교 포인트 · 3박 총비용 / 시내 접근성 / 짐 보관 / 호텔 이용 시간 / 새벽 공항 이동
숙박 선택은 두 일정에 공통흐바르·스플리트 선택과 별개로 결정할 수 있습니다. 숙박 요금은 아직 반영하지 않았습니다.
